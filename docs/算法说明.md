# 最终流程与工程设计

1. ALIKED-N32 分块提取特征，LightGlue 匹配；沿用用户前端、匹配方式和静止点过滤。
2. 固定外部内参，评估初始图像对的多视图稳定性，选择候选并增量注册相机。
3. 从完整已验证匹配图提出三维假设，解决特征归属和同相机冲突，保留待定观测。几何一致但未进入 BA 的特征可提供连接证据。
4. 联合重新拟合和留一视角预测检查轨迹合并；补全同时检查匹配支持、预测误差与候选歧义。
5. 维护阶段使用正深度及 4 px 观测上限限制 BA 步长，并保留进入该阶段的观测。前置重建仍允许移出不合格观测。
6. 导出去畸变、主点居中的 PINHOLE 相机与彩色点云，交给同一份 2DGS 训练和渲染。

最终采用原 witness_maintain 的算法参数：轨迹 RMS 上限 2.5 px、留一预测上限 6 px；补全的多链接预测阈值 3 px，单链接为 2 px，并要求足够的既有视角；两个归属候选误差差不足 1 px 时暂缓。重建和维护的轮数、BA 求解器与旧最终算法保持一致。

整理只统一源码、入口与结果管理，不宣称新增精度收益。历史测试中的较低重投影残差不能单独证明更准确：留出预测没有测得相对 COLMAP 的明确优势，2DGS 结构与感知指标也未全面胜出。完整历史证据随原包归档。
