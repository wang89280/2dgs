# 保持 ALIKED + LightGlue 的后端改进：资料与实验

核验日期：2026-10-14。本文区分文献原方法、本次实现以及尚未验证的设想，不能把文献在其他数据集的提升套到本项目。

| 一手来源 | 可参考的部分 | 本轮实际做了什么 |

## 更值得继续推进的路线

1. **带可见性检查的 featuremetric BA**：ALIKED/LG 的初始点和匹配保持不变，在 SfM 后端从原图提取用于局部精化的特征，优化三维点与相机；对遮挡、跨轮廓、相关响应多峰的观测避免强制固定点约束。需要验证特征在种子重复条纹上的局部可定位性，不能仅因为论文有效就承诺涨点。
2. **轮廓观测与实体表面点分开建模**：轮廓采用轮廓/切线或轮廓距离约束，稳定内部纹理仍用点重投影约束。简单地把边缘点降权，已经在本轮测试，不能算完成这个模型。
3. **评估增加独立证据**：现有原始留出坐标仍全部保留，避免筛点制造提升；另行增加独立几何/姿态真值，或事先锁定、人工审查且对方法盲测的实体表面点集。现有测试反映原始匹配轨迹的预测一致性，不等价于真实几何误差。

这些是后续研究方案，不是已验证的有效创新。本轮实际结果见 `outputs/track_covariance_20261014/实验报告.md`。
