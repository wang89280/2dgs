# 轨迹恢复开关与配对消融

本次新增实验开关，没有另建算法版本。默认 ON 的几何计算保持原样。轨迹指同一个三维点在不同图像中的特征观测集合；相机位置会通过 BA 随之变化，但该模块并非相机轨道平滑或轨迹插值。

## 开关范围

| 步骤 | ON | OFF |
|---|---|---|
| ALIKED、LightGlue、几何验证、静止点过滤、初始化、增量 SfM | 相同 | 相同 |
| 完整匹配图上的假设扩展、连接证据、独占分配、轨迹重组 | 开启 | 跳过 |
| 前置 3 轮固定内参 BA 与常规异常观测/小夹角过滤 | 保留 | 保留 |
| 几何验证的轨迹合并、待定观测补回 | 开启 | 跳过 |
| 正深度与 4 px 上限约束的固定内参 BA | 按原规则最多 3 次 | 普通入口 3 次；配对脚本重放 ON 的调用次数 |
| 原始像素、内参、唯一特征归属、每轨迹每图唯一观测审计 | 保留 | 保留，并断言无新增或重新分配观测 |

OFF 允许常规过滤删去异常观测；不能把它误写成完全不做后处理的 BASE。ON 内部的几何候选选择属于被消融的恢复模块。ON/OFF 各自保留的观测不完全相同，因此重投影 RMSE 不能单独用于判断几何精度。

## 新图片的使用

在总包根目录 PowerShell 中运行，结果自动使用不同时间戳目录：

```powershell
./run.ps1 -Images 'F:/path/to/images' -SparseOnly -TrackRecovery
./run.ps1 -Images 'F:/path/to/images' -SparseOnly -TrackRecovery:$false
```

Python 参数为 `--track-recovery` / `--no-track-recovery`。在 `config.json` 修改 `track_recovery` 可改变默认值。程序把本轮设置写入配置、命令记录及模型摘要。

## 严格配对实验

```powershell
# 使用本机已配置的 colmap Python 环境，在总包根目录运行
& "$env:USERPROFILE/Miniconda3/envs/colmap/python.exe" -B tools/run_track_ablation.py
# 可显式指定输入、输出；源目录需包含 2-1、3-1、4-1，各有 full 和 holdout
& "$env:USERPROFILE/Miniconda3/envs/colmap/python.exe" -B tools/run_track_ablation.py --source 'F:/path/to/runs' --output 'F:/path/to/new_ablation'
```

输入沿用 2026-10-12 三组数据的缓存：每组 full/holdout 各取相同的基础模型（历史文件夹名 `V2`）、完整验证图与固定内参。无需重新提取匹配、初始化或训练 2DGS。历史目录名只用于读取已有证据，不代表恢复多个开发版本。

实验输出 `outputs/track_recovery_ablation_20261014/<组>/<full或holdout>/`：

- `BASE/`：基础模型的指标和点云，`source.json` 指向保留的原始模型。
- `OFF/model/`：关闭恢复的模型、`sparse.ply`、优化日志和审计。
- `ON/model/`：开启恢复的模型、`sparse.ply`、优化日志和审计。
- `ON/rebuild/`、`OFF/rebuild/`：消融需要保留的中间阶段。
- `result.json`：三列结果、优化调用/实际步数与留出预测的配对区间。

先冻结协议、源码、程序和输入哈希，再运行 ON；从它的维护日志读取 BA 调用次数，让 OFF 重放相同调用预算。这个次数在读取预测指标之前确定，不按测试分数选择。每次 BA 保持同样的最多 5 次 IRLS、每次最多 25 个线性迭代及早停规则；实际接受步数、耗时、线性系统规模可能不同，不能称为完全相等的计算量。

脚本支持按完成标记续跑；已完成阶段校验后复用，中断阶段先保留再恢复。输入或冻结代码变化时拒绝混用同一输出目录。原始匹配库、基础模型、历史结果、前端与 2DGS 代码均只读并校验哈希。

## 指标与边界

主指标是原组内留出特征的查询预测误差：用交替观测作为三角化锚点和查询，固定相机，锚点拟合三维点后预测查询像素。报告误差截断到 20 px 的均值（失败记 20 px）、未截断统计和 3 px 命中率。ON−OFF 越负越好；以轨迹为配对单位做 2,000 次 bootstrap，种子 24002，报告 95% 区间。

训练图和基础模型会重新检查与测试特征/像素没有交集。该划分以前已被检查过，轨迹划分最初使用全量匹配拓扑；它是复用的组内特征留出，不是全新独立场景或独立几何真值。区间也不是跨场景泛化保证。

同时报告配准相机数、稀疏点数、观测增删/保留、独立视角轨迹长度、各自观测上的 RMSE、优化步数。此次是恢复模块整体的消融，不能进一步将收益归因于单个连接证据、合并或补全子步骤，也不能直接替代 ON/OFF 的 2DGS 对照。没有尺度真值，不能宣称毫米精度或 99% 接近 Metashape。
