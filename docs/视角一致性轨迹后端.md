# 视角一致性轨迹后端

本次新增 `view-consensus`，ALIKED-N32、LightGlue、原始像素坐标和标定内参均保持不变。它在已有稀疏重建之后重组观测轨迹，针对一条长轨迹无法由同一三维点解释的问题。它不是 Metashape 的原厂代码，也不是完整 Progressive-X 或 TC-SfM 实现。

## 使用

在本包目录打开 PowerShell：

```powershell
# 开启本轮新模块，只生成稀疏模型与标准导出数据
./run.ps1 -SparseOnly -TrackPartition view-consensus
# 关闭新模块，保留既有 SfM 与原轨迹恢复
./run.ps1 -SparseOnly -TrackPartition off
# 只检查转发命令，不运行提取、匹配或重建
./run.ps1 -SparseOnly -TrackPartition view-consensus -DryRun
```

Python 参数为 `--track-partition off|view-consensus`。默认 `off`；不要把此开关和原来的 `--track-recovery` 混为一谈。原来的轨迹恢复做重组、合并、补回；本轮模块把存在几何冲突的单轨迹解释为少量三维点，不增加新的图像观测。

已有模型无需重新运行前端：

```powershell
& "$env:USERPROFILE/Miniconda3/envs/colmap/python.exe" code/sfm/view_consensus_stage.py `
  --input '已有模型的根目录（其下包含 sfm）' `
  --output '尚不存在的新结果目录'
```

输出包括 `sfm/` 原生模型、`sparse.ply`、`metrics.json`、`partitions.json`、`view_consensus.json`。`partitions.json` 保存父子点身份、所属相机、训练误差和内部验证误差；可以恢复原观测对应关系。参数固定在 `code/sfm/python/view_consensus_partition.py` 的 `POLICY` 中。

## 实际算法

1. 从相机中心拟合主平面，以视角角度定义邻域；轨迹从最大可见性间隙展开，处理图像首尾环绕。非近似平面环绕拍摄保留原模型。
2. 每个候选子轨迹至少有 3 个视角。搜索所有满足长度约束的切分位置，用 DLT 提议，再对前三个候选做 soft-L1 三角化；所有子点需满足正深度和至少 2° 的三角化角。
3. 加入模型复杂度代价；训练平方误差至少降低一半，而且逐点留一验证误差至少降低 25%，才接受分段。每个父轨迹最多输出 3 个子点。
4. 交替执行按重投影误差分配观测、重新拟合三维点，再次做内部留一验证。这个步骤修正初始几何排序的边界误分。
5. 保留每个原始观测的像素和元数据，仅修改点身份与三维坐标。默认模块保持相机姿态与内参逐字节不变。实验另设同预算联合 BA 对照，单独判断相机收益。

模块评估时只把锚点传给上述算法；测试视角依据相机位置选择最近的锚点所属子模型。测试像素只在最终打分时读取。失败预测记为 20 px，不删除；每组 2,000 条既有留出轨迹。该测试测量的是多点轨迹解释的预测能力，不是相机姿态精度，也不是三维表面真值误差。

## 文献与使用范围

- Linfei Pan, Dániel Baráth, Marc Pollefeys, Johannes L. Schönberger. **Global Structure-from-Motion Revisited**, ECCV 2024。[论文](https://demuc.de/papers/pan2024glomap.pdf)、[官方仓库](https://github.com/colmap/glomap)。本轮直接调用 PyCOLMAP 4.0.4 内集成的 global mapper 作为对照，复用同一 ALIKED/LightGlue 数据库；它未作为默认后端。
- Daniel Barath, Jiri Matas. **Progressive-X: Efficient, Anytime, Multi-Model Fitting Algorithm**, ICCV 2019。[论文](https://arxiv.org/abs/1906.02290)、[官方仓库](https://github.com/danini/progressive-x)。借鉴多模型假设、几何分配和模型整合的思路。本模块没有使用其 GC-RANSAC、PEARL、图割或概率终止实现，不能称为该论文复现。
- Lei Wang, Linlin Ge, Shan Luo, Zihan Yan, Zhaopeng Cui, Jieqing Feng. **TC-SfM: Robust Track-Community-Based Structure-from-Motion**, arXiv:2206.05866，2022。[论文](https://arxiv.org/abs/2206.05866)。这里只作相关工作对照；其社区是由多条轨迹组成的场景片段，与本模块在一条轨迹内部拆分观测不同。本轮未确认官方公开代码，也未运行该方法。
- Geoff Cross. **Surface Reconstruction from Image Sequences: Texture and Apparent Contour Constraints**, Oxford 博士论文，2000。[机构页面](https://www.robots.ox.ac.uk/~vgg/publications/2000/Cross00a/)。支持将纹理与轮廓作为不同信息源处理的研究方向；本轮没有实现其曲面重建方法。

本算法对环绕采集作了几何假设，短轨迹仍使用原结果。拆分意味着增加自由度并缩短部分轨迹；点数增加不能解释为恢复了更多真实表面。轮廓处随视角变化的表观对应关系，即使能被局部三维点更好解释，也未被证明是固定物理特征。要判断尺寸、形状和毫米误差，需要独立几何真值。
