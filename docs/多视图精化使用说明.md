# 多视图精化：现有最终工程内的可选后端

前端仍是 ALIKED-N32 + LightGlue，内参与畸变参数仍固定。原有默认设置
`image_refinement: off` 保留。新增 `multiview` 选项用于可重复实验，不承诺精度提升。

在工程目录运行，仅重建稀疏点云：

```powershell
./run.ps1 -Images 'F:\03_matlab_python\352_seed_3dgs\04_new_calib_seed\seed_imgs\1011_imgs\1-1' -SparseOnly -ImageRefinement multiview
```

已经有本工程原生 SfM 模型时，可省略前端与初始化：

```powershell
python code/sfm/multiview_refinement_stage.py --source EXISTING_MODEL_ROOT --images SHARED_IMAGES --output NEW_MODEL_ROOT --logs NEW_LOG_DIRECTORY
```

`EXISTING_MODEL_ROOT` 必须含 `sfm/observations.bin`、`camera_ids.bin`、
`poses.bin`、`points.bin`、`calibration.bin`、`active_points.bin` 与 `cameras.xml`。
`NEW_MODEL_ROOT` 必须不存在；图像标签必须能在 `SHARED_IMAGES` 精确解析。
原始模型、图像、特征匹配、历史实验不会被覆盖。

处理顺序：

1. 将原生像素中心转换为网络图像坐标；每张图像缩放到长边 1200，RGB LANCZOS。
2. 从已有轨迹裁剪 35×35 图块，调用 DenseSfM 发布的 S2DNet、多视图 Transformer 与 GP 精化网络。
3. 每条轨迹最多同时处理 16 视图；长轨迹分段，锚点首次移动，之后按新位置裁剪并固定。
4. 对训练轨迹做偶/奇视图交叉检查。至少 4 个视图、位移不超过 6 px、全轨迹 DLT 重投影 RMSE ≤2 px，且交叉预测误差降低至少 10%，才接受整条建议；否则恢复原始坐标。
5. 用同一套原生固定内参 robust BA 做 3 次优化。不删观测、不合并轨迹、不修改特征描述子。
6. 逐身份核对输入/输出与内参，导出 `sparse.ply`、`metrics.json`、`image_refinement.json` 和原始测量证据。

工程新增代码：

- `code/sfm/multiview_refinement_stage.py`：用户入口和整合。
- `code/sfm/python/multiview_refinement.py`：预训练网络、图像与轨迹适配。
- `code/sfm/python/densesfm_roi.py`：与官方端点约定一致的 PyTorch 裁剪。
- `code/sfm/python/multiview_consistency.py`：只使用训练观测的几何检查与整轨迹回退。
- `code/sfm/bin/refine_multiview_observations.exe`：原生固定内参 BA；与原 BA 相同，仅放宽输入观测位移的硬校验上限。
- `tools/run_multiview_refinement.py`、`tools/run_multiview_guard.py`：同预算消融；前者保留未经几何检查的直接网络分支。

用户入口 `run.ps1` / `run_pipeline.py` 的 `multiview` 总是带一致性检查。
底层 `image_refinement_stage.py` 的 `multiview` 是直接网络消融接口，正常使用应走上面的统一入口。
这是工程接入而非原创网络；官方代码、权重来源和修改范围见
`code/sfm/third_party/densesfm/INTEGRATION.md`。没有使用 RoMa v2 前端或 Metashape。

运行环境需要 CUDA PyTorch/torchvision，以及 `code/sfm/requirements-multiview.txt`。
在本机 colmap 环境中，严格权重加载、裁剪参考计算、官方前向等价、分批不变性与已知场景几何测试均已执行。

测量坐标发生变化后，自身重投影 RMSE 会变得不可直接比较。判断是否涨点应先看
`outputs/multiview_refinement_20261014/多视图精化测试报告.md` 的原始留出指标。
没有三维真值时，不将任何训练残差的降低解释为毫米精度或“99% 接近原厂”。
